# Pac-Man Game using Python

AI-controlled Pac-Man game built with Python and Pygame.

## Features
- Pac-Man movement
- Ghost AI using A* Algorithm
- Score system
- Collision detection
- Game board and assets

## Technologies Used
- Python
- Pygame
- A* Pathfinding Algorithm

## How to Run

```bash
pip install pygame
python pacman_astar6.py
```
